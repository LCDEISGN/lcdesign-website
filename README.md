# L.C.DESIGN v4 — 代表プロフィール追加版

## 更新手順

1. ZIPを「すべて展開」します。
2. GitHubで「ファイルを追加」→「ファイルをアップロード」を開きます。
3. **index.html / style.css / script.js / favicon.svg / daiki-haraguchi.png** の5ファイルをまとめてドラッグします。
4. 「変更をコミット」を押します。CNAMEはそのまま残します。既存ファイルの事前削除は不要です。
5. 公開完了後、Ctrl + F5で再読み込みしてください。

写真もindex.htmlと同じ場所に入れます。フォルダーは不要です。このREADMEは手元で読むだけでも構いません。
