## GitHubでの更新

1. ZIPを展開します。
2. 現在 lcdesign.page を公開している GitHub リポジトリで「ファイルを追加」→「ファイルをアップロード」を開きます。
3. `index.html`、`style.css`、`script.js`、`favicon.svg`、`daiki-haraguchi.png`、`README.md` の6ファイルをまとめてアップロードして変更をコミットします。
4. リポジトリにある `CNAME` は残してください。
5. 公開反映後、ブラウザを強制再読み込みして確認してください。
