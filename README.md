# L.C.DESIGN 動き強化版

## 更新はこの4ファイルだけ

1. ZIPを「すべて展開」します。
2. GitHubの「ファイルを追加」→「ファイルをアップロード」を開きます。
3. 展開した `index.html`、`style.css`、`script.js`、`favicon.svg` を4つまとめてドラッグします。フォルダーは不要です。
4. 「変更をコミット」を押します。既存ファイルは削除しなくて大丈夫です。CNAMEはそのまま残してください。
5. GitHub Pagesの更新完了後、公開サイトで Ctrl + F5 を押して再読み込みします。

このREADMEは手元で読むだけでも構いません。favicon.svgはindex.htmlと同じ場所に置く構成に変更しています。

## 変更内容

- INPUT：文字がスクロールに合わせて立体回転・浮上・フェードアウト。中央付近に読みやすい静止区間を設けています。
- 左の図：縮小をやめ、線とノードの回転へ変更。
- PROCESS：大きな縦型工程表示へ変更。目的・優先順位、専門性・役割、品質・コスト・納期、検証と意思決定、導入・運用というプロジェクトマネジメントの役割を紹介。
- 事業カード：奥行きのある立ち上がり。Works：傾きながら浮上。
- 「未来を、構想で終わらせない。」：動きを止めて表示。
- OSの「動きを減らす」設定ではアニメーションを停止。JavaScript無効でも本文とメールリンクを利用できます。

問い合わせ：info@lcdesign.page。メールアプリを開く方式です。
