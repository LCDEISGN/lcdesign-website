# L.C.DESIGN / 全画面スクロール版 v3

## 更新方法 — この4つを入れるだけ

1. ZIPを右クリックして「すべて展開」します。
2. GitHubのいつものリポジトリで「ファイルを追加」→「ファイルをアップロード」を開きます。
3. 展開した **index.html / style.css / script.js / favicon.svg** の4つをまとめてドラッグします。
4. 「変更をコミット」を押します。事前の削除は不要です。**CNAMEはそのまま残してください。**
5. 公開処理が終わってからサイトを開き、Ctrl + F5で再読み込みします。

このREADMEは手元で読むだけで構いません。フォルダーをアップロードする必要はありません。ファイル名は変更しないでください。

## 新しい流れ

問い「What comes next?」→巨大な「L.C.DESIGN」→Future / Dream / Imagination / Technology / Data / Experience→PMとして工程をつなぐ→白い静止画面のメッセージ→事業紹介。

スクロールすると同じ画面内で文字と背景が変化します。逆方向にスクロールすると演出も戻ります。ゆっくりスクロールすると登場・静止・退場が確認できます。画面が止まっているように見える場面も、そのままスクロールしてください。

PCでは冒頭約3.7画面、INPUT約6.2画面、PM約6.4画面分のスクロールで進みます。読み飛ばしたい場合は冒頭の「事業紹介へスキップ」を使えます。

## 表示・設定

- 問い合わせは info@lcdesign.page。メールアプリを開きます。
- 連絡先を変更する場合はindex.html内のアドレスをすべて置き換えてください。
- 「動きを止める」で通常の縦読み表示に切り替えられます。再開もできます。
- OSの「動きを減らす」設定を尊重します。この設定中はサイト側で動きを再開しません。
- JavaScript無効時は通常の縦読み表示です。
- 外部動画・フォント・ライブラリ・ビルドは不要。背景は軽量なCanvas描画です。常時動かし続けずスクロール時に描画します。
- Worksはコンセプトです。実在のプロジェクト実績は未掲載です。
- Appleの画像・映像・ロゴは使用していません。
