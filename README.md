# L.C.DESIGN ホームページ

漆黒の導入 → INPUT → 実現のプロセス → 白い宣言 → 事業紹介、という構成のGitHub Pages用サイトです。パソコンへの開発ソフトのインストール、ビルド、コマンド操作は不要です。

## ファイル

```text
index.html          ページの本文
style.css           色・レイアウト・スマホ対応
script.js           スクロール演出・お問い合わせ設定
assets/favicon.svg  ブラウザーのタブに出るアイコン
.nojekyll           GitHub Pagesでそのまま配信するための目印
README.md           この説明書（公開しても問題ありません）
```

背景、球体、線、作品イメージはCSS・SVGで描画しています。外部フォント、CDN、動画、解析ツール、Cookie、外部ライブラリを使いません。

## 最も簡単な導入方法：ファイルをアップロード

1. ZIPをパソコンで展開します。
2. GitHubで公開先のリポジトリを開きます。新規の場合は右上の「＋」→「New repository」で作成してください。GitHub Freeで公開する場合はPublicを選びます。すでにサイトがある場合は、先に既存ファイルをダウンロードして保管してください。
3. リポジトリの「Code」画面で「Add file」→「Upload files」を選びます。
4. `lc-design`フォルダーの**中身**をアップロードします。`index.html` がリポジトリ直下に来るようにしてください。フォルダーごと入れて `lc-design/index.html` にしないでください。`assets`だけはフォルダーのまま入れます。
5. 「Commit changes」で保存します。既存ファイルと同名のものは、このサイトの内容に置き換わります。
6. 下の「公開設定」へ進みます。

## コピーペーストで導入する方法

ファイルの中身をテキストエディターで開き、全選択してコピーします。HTMLをダブルクリックするとサイトが開くので、右クリック→「プログラムから開く」→「メモ帳」などを選んでください。

1. GitHubの「Code」画面で「Add file」→「Create new file」を選びます。
2. ファイル名に `index.html` と入力します。
3. 本文欄に、配布した `index.html` の内容をすべて貼り付けます。チャットの囲み記号などは不要です。
4. 「Commit changes」を押して保存します。
5. 同様に `style.css` と `script.js` を作り、各ファイルの内容を貼り付けます。
6. ファイル名に `assets/favicon.svg` と入力して作成します。`/`を入力するとフォルダーも作成できます。配布ファイルの内容を貼り付けます。
7. `.nojekyll` という名前のファイルを作ります。本文は空白で構いません。空白では保存できない場合は、1行だけ `Static site` と書いてください。ファイルの存在が目印です。
8. `README.md` も同じ方法で保存すると、後で手順を確認できます。

同じ名前のファイルがすでにある場合は、新規作成ではなくファイルを開き、鉛筆アイコンの「Edit this file」から本文を全置換して保存します。大文字・小文字、拡張子まで一致させてください。`index.html.txt` は別のファイルです。

## 公開設定

1. リポジトリ上部の「Settings」を開きます。
2. 左側の「Pages」を開きます。
3. 「Build and deployment」の「Source」を **Deploy from a branch** にします。
4. 「Branch」でファイルを保存したブランチ（通常は `main`）、フォルダーで **/(root)** を選び、「Save」を押します。
5. 配信が完了すると「Pages」に公開URLが表示されます。反映まで数分かかる場合があります。「Actions」で処理状況を確認できます。
6. 表示されたURLを開きます。通常は `https://ユーザー名.github.io/リポジトリ名/` です。

手順確認元：[GitHub公式：公開元を設定する](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[サイトを作成する](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。確認日：2026-09-16。

`lcdesign.page` など独自ドメインの設定は、この配布物には含めていません。既存リポジトリに `CNAME` がある場合は保持してください。CSS・JavaScript・アイコンは相対パスなので、リポジトリ名付きのURLにも対応します。

## すでに設定済みの内容

- お問い合わせ：**info@lcdesign.page**
- 問い合わせボタンはメールアプリを開きます。Web上でメールを送るフォームではありません。メールアプリ未設定の場合は、表示されているアドレスをコピーしてご利用ください。
- Worksは「コンセプトビジュアル」「個別のプロジェクト実績は公開準備中」と明記しています。架空の顧客、実績数、受賞歴は掲載していません。
- 住所、代表者名、法人情報は未提供のため掲載していません。

## よく変更する場所

### 本文、事業内容、会社情報

`index.html` で表示中の日本語を検索し、該当する文章を書き換えます。見出しの前後にある `<h2>` などの記号は残します。会社情報は `id="about"` のセクションにあります。

### 連絡先

`script.js` 冒頭の `contactEmail` を変更します。JavaScriptが無効でも使えるよう、`index.html` にあるメールアドレス（リンク先も含む）もすべて同じ内容に変更してください。

フォームを使う場合は、`contactUrl: ''` の引用符内に実際の `https://` フォームURLを入れます。フォームを優先して表示します。`index.html` の問い合わせボタンの `href` も同じURLに変更してください。外部フォームサービスの設定や個人情報の取り扱い案内は、そのサービスに合わせて用意してください。

### 実績を追加する

`index.html` の `id="works"` を検索します。掲載許可のあるプロジェクト名・概要・画像に差し替えたら、「コンセプト」「公開準備中」の説明も実情に合わせて変更してください。現在のカードは詳細ページのない紹介表示で、クリックリンクではありません。画像を追加する場合は `assets/` に保存し、画像の内容がわかる `alt` を付けてください。

### 色、余白、動き

`style.css` の冒頭 `:root` に主な色をまとめています。文字や背景を変更する際は読みやすいコントラストを保ってください。常時点滅や自動再生は使わず、スクロールによる文字の強調とノードの収束に抑えています。

## 表示とアクセシビリティ

- スマホでは2列のINPUTを1列にし、横スクロールを防ぎます。
- パソコンではINPUT左側を固定し、右側の言葉に合わせて線の集まりが収束します。
- ページ上部から事業紹介へスキップできます。キーボードのTabキーで「本文へスキップ」が現れます。
- OSで「視差効果を減らす／アニメーションを減らす」を設定すると、フェード、収束、滑らかなスクロールを止めます。
- JavaScript無効時も本文、ナビゲーション、メールリンクは利用できます。
- スクロールを強制する仕組みや、マウスを追いかけるカーソルはありません。

## 公開後の確認

スマホとパソコンでページを開き、上部ナビゲーション、Contactのメールアドレス、表示内容を確認してください。更新されないときは再読み込みしてください。デザインが消えて本文だけになる場合は、`style.css` が `index.html` と同じ階層にあるか確認します。404の場合はPages設定のブランチとフォルダー、`index.html`のファイル名を確認してください。

ローカル確認は `index.html` をダブルクリックするだけで可能です。実際のGitHub Pages配信とメールの受信可否は、公開後にご確認ください。
